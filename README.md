# Еквалайзер для TB520FU

Мінімальний системний еквалайзер: одна активність, ніяких сторонніх бібліотек, ніяких дозволів
крім `MODIFY_AUDIO_SETTINGS`. Працює через штатний AOSP-ефект `Equalizer` (той, що дає
`libbundlewrapper.so`), а не через Dolby — бо в нашому порті PixelOS профільні параметри Dolby
інертні (див. `lenovo-sm8650/android_device_lenovo_lapis#7`).

## Вимога, під яку писалося

**Не падати й не відвалюватися.** Тому:

- ефект живе в `Application`, а не в активності — не зникає, коли екран пішов у фон;
- кожен виклик обгорнутий у try/catch: жодна помилка ефекту не вбиває застосунок;
- сторож кожні 5 с перевіряє, що ефект приєднаний і ввімкнений, і переприєднує його після
  перезапуску `audioserver` або втрати контролю — саме так системні ефекти «відвалюються»;
- рівні смуг зберігаються і повторно застосовуються після кожного переприєднання.

## Збірка

CI збирає debug-APK (особистий застосунок, ставимо через adb, у стор не йде):

```bash
gh run download -n eq-apk
adb install -r eq.apk
```
